# MUHADIR Invitation Page

Standalone one-screen Arabic invitation card for MUHADIR participation in معرض إنجاز 2026.

Open directly:

```text

```

## Personalized Links

```text
General:
invitation/index.html?type=general

Doctor example:
invitation/index.html?type=doctor&title=د&name=محمد%20جبلي

Engineers Batch 44:
invitation/index.html?type=engineers44

Major colleague example:
invitation/index.html?type=colleague&title=م&name=إيلاف%20الغامدي
```

For doctor and colleague invitations, change `name` and optionally `title` in the URL to send the same invitation to different people.
